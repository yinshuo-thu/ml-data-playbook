# 时间序列

运行 `python -m time_series.forecasting`，输出模型 RMSE、同周期朴素基准及预测 CSV。
数据为固定种子的合成日序列，包含周周期与趋势。

特征：前一天 `lag1`、前一周 `lag7`、先 shift 再计算的历史七日均值、星期。
先按时间构造只依赖过去的信息，再按时间切分；没有 shuffle。

## 本例的信息假设

每天在拿到昨天的真实目标后，预测今天：**一步滚动预测（one-step rolling forecast）**。
所以验证期后面的样本可以使用验证期前面已经发生的真实值。
如果在同一天一次性预测未来整月，这个做法会使用未来不可得标签；需要递归预测、直接多步模型或已知外生特征。

## 常见扩展

- 多实体：先按实体和时间排序，shift/rolling 只能在实体内部计算。
- 不规则时间：明确窗口按条数还是按时间长度。
- 未来区间标签：按真实标签可用时间设置 gap/purge。
- 同时刻多行：按唯一时间戳划分，不能仅按行位置切开同一时刻。
- 标准化：只在每个训练区间 fit。
