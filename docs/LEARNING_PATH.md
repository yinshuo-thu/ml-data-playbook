# 推荐阅读路线

1. `numpy_basics/arrays.py`：能解释 shape、axis、广播和布尔索引。
2. `data_analysis/cleaning.py`：理解类型转换、缺失、重复、异常隔离。
3. `groupby_reshape.py`、`joins.py`：能写分组汇总，知道连接基数为何重要。
4. `visualization/eda_report.py`：看分布、关系、缺失，提出问题。
5. `docs/VALIDATION_AND_LEAKAGE.md`：先设计验证，再建模。
6. `machine_learning/regression.py` 与 `playbook/modeling.py`：理解 fit/transform/predict。
7. `classification.py`、`tuning.py`：选择指标并比较参数。
8. `cases/house_prices/README.md`：完整处理真实比赛，不跳过数据字典。
9. `time_series/`：理解一步与多步预测的信息差异。
10. `deep_learning/tensors.py` → `mlp.py` → `cnn.py` / `sequence.py`。

每次迁移到自己的数据，只改一组假设，记录代码版本、划分方式、指标与结果。
日常查阅无需按顺序学习，直接从 [问题索引](TASK_INDEX.md) 找对应入口。
