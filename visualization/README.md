# 可视化与 EDA

运行 `python -m visualization.eda_report`。
使用离线合成混合类型数据，输出 `outputs/eda/report.png`，不弹出桌面窗口。

图包括目标分布、一个特征与目标的散点、数值特征相关性、缺失比例。
运行环境使用 Agg 后端，适用于服务器和自动检查。

迁移时先划分开发与预留部分，仅用开发标签探索模型规律。
相关性只衡量所选统计关系，不能证明因果；高相关也不能单独决定删特征。
图片保存后关闭 figure，防止循环画图占用内存。
